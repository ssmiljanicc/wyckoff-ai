# Phase C — Test

## Summary

**Phase C** is the **third** structural phase of a Wyckoff range. Its
function: the operator **verifies** that the path of least resistance
is in their favor by testing the level of interest from the opposite
side ([book p.184](../../../raw/book/pages/page_184.md)).

Phase C begins with the **start of the shake event** and ends after
the **shake test**.

The events of Phase C are
([book p.184](../../../raw/book/pages/page_184.md)):

- [[spring|Spring / Shakeout]] — downward shake in accumulation /
  reaccumulation
- [[upthrust-after-distribution|Upthrust After Distribution (UTAD)]] —
  upward shake in distribution / redistribution
- (or no shake — see [[no-shake-phase-c]])

## Key Points

### What Phase C Tests

The shake is **not** a position-building event — by Phase C, the
operator's position is already largely filled (Phase B did that). The
shake's purpose is to **verify** that no significant remaining
participation will fight the eventual trend move
([book p.184](../../../raw/book/pages/page_184.md)):

- Push price through the structural boundary in the **opposite**
  direction of the expected trend.
- If the move **finds significant participation** (volume, follow-through,
  no quick reversion), absorption is **not complete** and the structure
  must extend Phase B.
- If the move **finds no participation** (price reverts quickly back
  into the range), the path of least resistance is verified.

This is [[path-of-least-resistance|verification through tests]] in
action.

### The Three Phase C Outcomes

1. **Shake confirms — the textbook path.** Spring or UTAD prints, the
   subsequent test holds inside the range, Phase D begins with the
   SOS / SOW.
2. **Shake fails.** The probe encounters significant opposite-side
   participation. Two options follow:
   - The operator **abandons the campaign** — price continues in the
     direction of the original trend (rare but explicitly named in the
     book ([book p.185](../../../raw/book/pages/page_185.md))).
   - **Phase B extends** — more tests inside the range until the
     remaining supply / demand is absorbed. A new Phase C attempt
     follows later.
3. **No shake.** Absorption was so thorough during Phase B that no
   final shake is needed. The structure resolves through an internal
   [[last-point-of-support|LPS]] / [[last-point-of-supply|LPSY]] —
   see [[no-shake-phase-c]].

### Shake May Not Sweep The Extremes

The book is explicit
([book p.185](../../../raw/book/pages/page_185.md)):

> "A very important aspect to bear in mind that can happen at this
> stage is that the shaking event will not necessarily sweep the
> extremes of the structure. Doing so is ideal because the greater
> this movement, the more liquidity you will have been able to capture
> and therefore the more 'gasoline' the subsequent movement will have.
> But it can also be the case that a Shake takes place without
> reaching the extremes."

When the shake stays inside the range, it can be labeled:

- **minor spring / minor UTAD** — internal shake that still produces
  the reversal.
- **LPS / LPSY** — the same action labeled functionally rather than as
  a shake event.

The book reinforces the [[labeling-is-last-step|labels-are-not-the-
point]] discipline here. What matters is the function (absorption is
complete, trend can begin), not the specific label.

### Phase C Is The Operational Phase

Phase C is where the **primary entry** of the methodology lives.
Before Phase C, the trader is in observation mode (Phase A) or
patient mode (Phase B). At Phase C, the spring test or UTAD test
provides the best risk/reward in the entire structure:

- Stop just outside the spring low / UTAD high.
- Target the Creek / Ice and beyond.
- See [[secondary-test|the spring test discussion]] for the entry
  rules.

A Spring #3 entry is takeable directly without a separate test. Other
spring types require the explicit Phase C test before the entry is
clean.

### Preconditions

For Phase C to be meaningful, two things must have happened
([book p.134](../../../raw/book/pages/page_134.md)):

1. **Phase A** — the previous trend has stopped.
2. **Phase B** — a significant cause has been built (absorption
   period).

A "shake" without these preconditions is just a continuation of the
trend, not a Phase C event.

## Why It Matters For Wyckoff Reading

- Phase C is the **highest-conviction entry phase**. The structure has
  built its evidence; the shake confirms or refutes the read.
- The three-outcome framework (shake confirms / shake fails / no
  shake) is the correct mental model for what Phase C **can** look
  like.
- Phase C entries are aggressive in terms of timing but **conservative
  in terms of stop placement** — the structural anchor for the stop
  is well-defined.
