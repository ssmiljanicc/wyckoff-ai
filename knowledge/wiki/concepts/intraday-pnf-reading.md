# Intraday P&F Reading

## Summary

**Intraday P&F reading** is Fraser's application of Wyckoff
[[point-and-figure-counting]] to shorter periods such as 60-minute, 30-minute,
5-minute, and similar charts. He says the same count techniques apply, but
events happen quickly and require intense attention
([Intraday Charts](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-03-point-and-figure-analysis-with-intraday-charts.md)).

Fraser's practical setup is to change the intraday period and use Dynamic ATR
scaling so the P&F box size fits the selected timeframe
([Intraday Charts](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-03-point-and-figure-analysis-with-intraday-charts.md)).

## Key Points

### Intraday Causes Can Be Counted

Fraser argues that cause-building on intraday timeframes is often missed, but
can still be counted, projected, and campaigned
([Intraday Charts](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-03-point-and-figure-analysis-with-intraday-charts.md)).

### Smaller Causes Nest Inside Larger Causes

In his QQQ and Nasdaq examples, smaller intraday counts can target the top of a
larger range while a longer intraday chart shows a bigger cause still forming
([Intraday Charts](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-03-point-and-figure-analysis-with-intraday-charts.md)).
The larger cause can set directional bias until a meaningful distribution count
appears
([Intraday Charts](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-03-point-and-figure-analysis-with-intraday-charts.md)).

### P&F Can Carry Tape-Reading Labels

Fraser's intraday-only case study shows that a 3-box P&F chart built from
5-minute data can display the same key Wyckoff events normally read from
vertical charts: SC, AR, ST, Spring, Test, MSOS, and BU
([Using Intraday](../../../raw/bruce_fraser/posts/articles-wyckoff-2018-11-using-pnf-charts-for-intraday-trading.md)).

### Intraday Distribution Can Precede The Larger Chart

In the February 2018 index decline, Fraser identifies the distribution and
change of character first in the intraday timeframe, then uses the fulfilled
intraday count to ask what new cause is forming
([Cause and Effect](../../../raw/bruce_fraser/posts/articles-wyckoff-2018-02-the-law-of-cause-and-effect-in-action.md)).

## Why It Matters For Wyckoff Reading

- It lets short-term traders use the same cause/effect logic without waiting
  for daily or weekly structures.
- It simplifies fast tape reading by compressing price into essential swings.
- It forces timeframe hierarchy: smaller counts can be tactical while larger
  counts set bias.
