# P&F Distribution Paradox

## Summary

The **P&F distribution paradox** is Fraser's warning that downside counts are
structurally different from upside counts. Accumulation counts can project very
large advances, but a distributed stock cannot fall below zero, so counting an
entire [[structures/distribution]] can produce impractical targets
([Distribution Paradox](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-02-the-point-and-figure-distribution-paradox.md)).

Fraser's answer is to count distribution selectively: find the places where the
vertical chart shows active selling and take smaller count segments that are
tactically useful
([Distribution Paradox](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-02-the-point-and-figure-distribution-paradox.md)).

## Key Points

### Start With The Distribution Boundary Rules

Fraser's standard distribution count begins at the LPSY and counts back toward
the BCLX or PSY, using up columns as the distribution count anchors
([Distribution Secrets](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-01-secrets-of-point-and-figure-distribution.md)).
That count is then used in reward/risk judgment, with conservative objectives
preferred for actual trade decisions
([Distribution Secrets](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-01-secrets-of-point-and-figure-distribution.md)).

### Over-Counting Is The Main Failure Mode

Fraser says distribution counts should be under-counted because only part of a
distribution may represent active C.O. selling, and full-range counts can imply
unusable below-zero objectives
([P&F Magic](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-01-point-and-figure-magic.md);
[Distribution Paradox](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-02-the-point-and-figure-distribution-paradox.md)).

### Count Active Selling Segments

In the Tesla example, Fraser looks for price peaks near resistance where volume
expands on the decline, then counts from the failed test back to the prior peak
([Distribution Paradox](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-02-the-point-and-figure-distribution-paradox.md)).
He treats those smaller segments as the measurable downside cause produced by
large-interest selling
([Distribution Paradox](../../../raw/bruce_fraser/posts/articles-wyckoff-2016-02-the-point-and-figure-distribution-paradox.md)).

### Redistribution Can Reconfirm Distribution

Fraser's bond case uses a redistribution count that approximately equals a
prior distribution count as evidence that the downtrend may resume
([Bonds](../../../raw/bruce_fraser/posts/articles-wyckoff-2017-02-bonds-shaken-not-stirred.md)).

### Percent Scale Is Usually Not For Downside Targets

Fraser's later percent-scale rules say distribution and redistribution
downside targets should default to arithmetic scale because log-scale P&F can
over-count downside objectives
([Percent Scale](../../../raw/bruce_fraser/posts/articles-wyckoff-2023-09-percent-scale-pnf-technique-nv-456.md)).

## Why It Matters For Wyckoff Reading

- It prevents large top formations from producing unusable downside targets.
- It keeps distribution analysis tied to visible C.O. selling rather than
  counting every volatile column.
- It makes downside targets decision zones for stopping action,
  redistribution, or fresh accumulation.
