# Bruce Fraser - P&F Intraday And Percent Scale

## What This Source Group Is

These articles cover Fraser's nonstandard P&F uses: intraday P&F for fast
campaigns and percent-scale/log P&F for dynamically rising instruments. Both
are applications of [[point-and-figure-counting]], not replacements for the
primary count discipline.

## Key Claims

- Intraday P&F uses the same count technique as longer timeframes, but Fraser
  changes chart period and scaling; he specifically points to intraday period
  selection and Dynamic ATR scaling
  ([Intraday Charts](../../../../raw/bruce_fraser/posts/articles-wyckoff-2016-03-point-and-figure-analysis-with-intraday-charts.md)).
- Intraday causes can nest inside larger causes, so Fraser uses smaller counts
  for tactical objectives while the larger count frames directional bias
  ([Intraday Charts](../../../../raw/bruce_fraser/posts/articles-wyckoff-2016-03-point-and-figure-analysis-with-intraday-charts.md);
  [Cause and Effect](../../../../raw/bruce_fraser/posts/articles-wyckoff-2018-02-the-law-of-cause-and-effect-in-action.md)).
- Fraser also shows that a well-constructed intraday P&F chart can carry the
  same Wyckoff labels normally read from vertical charts, including SC, AR, ST,
  Spring, Test, MSOS, and BU
  ([Using Intraday](../../../../raw/bruce_fraser/posts/articles-wyckoff-2018-11-using-pnf-charts-for-intraday-trading.md)).
- Percent-scale P&F changes the arithmetic: each counted column represents a
  compounding event rather than a fixed price unit
  ([NASDAQ Throwover](../../../../raw/bruce_fraser/posts/articles-wyckoff-2020-07-a-nasdaq-100-throwover-is-the-783.md);
  [Percent Scale](../../../../raw/bruce_fraser/posts/articles-wyckoff-2023-09-percent-scale-pnf-technique-nv-456.md)).
- Fraser limits the percent-scale method: use it mainly for dynamically rising
  and volatile instruments, count conservatively, default to 1-box reversal,
  and use arithmetic scale for distribution/redistribution downside targets
  ([Percent Scale](../../../../raw/bruce_fraser/posts/articles-wyckoff-2023-09-percent-scale-pnf-technique-nv-456.md)).
