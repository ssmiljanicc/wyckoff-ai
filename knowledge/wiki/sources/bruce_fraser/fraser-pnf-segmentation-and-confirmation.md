# Bruce Fraser - P&F Segmentation And Confirmation

## What This Source Group Is

These articles cover how Fraser avoids over-counting and how he treats
matching counts across structures as useful campaign evidence. The emphasis is
not a new definition of [[point-and-figure-counting]]; it is a practical
discipline for deciding which part of a range is countable cause.

## Key Claims

- Large structures can be counted, but Fraser first evaluates the entire
  structure and then looks for smaller, more conservative counts inside the
  larger cause
  ([Monster Charts](../../../../raw/bruce_fraser/posts/articles-wyckoff-2016-01-counting-monster-point--figure-charts.md)).
- Reaccumulation pauses are countable stair-steps in an ongoing uptrend; Fraser
  counts from the LPS back to the appropriate reaction/AR area after labeling
  the vertical chart
  ([Pauses](../../../../raw/bruce_fraser/posts/articles-wyckoff-2016-02-point-and-figure-pauses-that-refresh.md)).
- A prior cause can be mostly spent before a new trendless area starts building
  another cause, so Fraser uses current counts to ask whether risk is rising
  near old objectives
  ([Current Counts](../../../../raw/bruce_fraser/posts/articles-wyckoff-2016-05-current-point-and-figure-counts.md)).
- Segmenting is Fraser's main answer to uncertain base quality: only the
  portion that shows actual accumulation should be counted, and Secondary Tests
  can act as segment boundaries
  ([Segmenting](../../../../raw/bruce_fraser/posts/articles-wyckoff-2017-05-segmenting-pnf-counts.md)).
- In his Dow case studies, Fraser treats reaccumulation counts that match a
  larger accumulation objective as confirming evidence that the uptrend can
  continue
  ([More Pie](../../../../raw/bruce_fraser/posts/articles-wyckoff-2017-06-more-pie-bigger-sky.md);
  [P&F Diary](../../../../raw/bruce_fraser/posts/articles-wyckoff-2017-07-point--figure-diary.md)).
- The later diary update frames P&F as a hurdle-rate tool: once a worthwhile
  objective exists, the analyst still has to reassess newly formed columns and
  the next range-bound condition
  ([Dear Diary](../../../../raw/bruce_fraser/posts/articles-wyckoff-2017-10-dear-point-and-figure-diary.md)).
