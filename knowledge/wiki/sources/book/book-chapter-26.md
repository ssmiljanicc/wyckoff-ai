# Book Chapter 26 — Primary Positions

## What This Chapter Is

Chapter 26 translates the event/phase framework into operating zones.
The book limits possible operations to three areas: Phase C at the
potential shake, Phase D during the trend within the range and the test
after the break, and Phase E trend-continuation setups after the range has
resolved ([p.198](../../../../raw/book/pages/page_198.md)).

The chapter's core tradeoff: earlier signals give more potential travel but
less reliability; later signals have more structural confirmation but less
remaining reward
([p.198](../../../../raw/book/pages/page_198.md)).

## Why It Matters

This chapter prevents event labels from becoming abstract vocabulary. It
orders the usable trade locations by structural maturity:

- Phase C has the best risk/reward because the entry sits at one end of the
  structure, but the range has had less development
  ([p.199](../../../../raw/book/pages/page_199.md)).
- Phase D entries use the successful shake/test background and look for
  continuation inside the range
  ([p.202](../../../../raw/book/pages/page_202.md)).
- The break-test entry is highlighted as Richard Wyckoff's favorite
  position because the full structure is already visible to the left
  ([p.204](../../../../raw/book/pages/page_204.md)).
- Phase E entries are safer because the previous accumulation/distribution
  is already confirmed, but the remaining path can be smaller
  ([p.204](../../../../raw/book/pages/page_204.md)).

## Key Claims

- Direct entry into a shake is recommended only when the shake develops
  with relatively low volume; high-volume shakes usually need a later test
  ([p.199](../../../../raw/book/pages/page_199.md)).
- A spring test should stay above the spring low; an upthrust test should
  stay below the upthrust high
  ([p.200](../../../../raw/book/pages/page_200.md)).
- A Phase C LPS/LPSY entry is harder to identify in real time because
  only the later structure break confirms that it was the last support/supply
  point ([p.201](../../../../raw/book/pages/page_201.md)).
- Phase D allows entries with [[significant-bar|significant bars]], minor
  structures, minor shakes, or the break-test/confirmation event
  ([p.202–204](../../../../raw/book/pages/page_202.md)).
- Minor structures and minor shakes inside the Phase D move should be
  functionally labeled as LPS/LPSY because they are turns in favor of the
  trend movement inside the structure
  ([p.203](../../../../raw/book/pages/page_203.md)).
- In Phase E, entries again use significant bars, minor structures, or
  shake events, but now the trader is operating in favor of a confirmed
  accumulation/distribution context
  ([p.205–206](../../../../raw/book/pages/page_205.md)).
- The chapter closes with a summary table that consolidates those trading
  opportunities by structural location
  ([p.207](../../../../raw/book/pages/page_207.md)).
